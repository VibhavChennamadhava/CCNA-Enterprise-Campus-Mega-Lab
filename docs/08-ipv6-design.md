# 08 - IPv6 Design

This section documents IPv6 design and implementation intent for the campus edge/core domain.

## Scope
- IPv6 unicast routing enablement
- Global unicast addressing on routed interfaces
- EUI-64 usage where configured
- Primary IPv6 default route and floating backup default route behavior

## Verification Status
Current repository includes partial config evidence of IPv6 routing enablement. Full operational verification (neighbor/routing-table/failover outputs) is pending export and should be added to verification artifacts.
