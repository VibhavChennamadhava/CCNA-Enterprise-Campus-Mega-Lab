# Diagram Sources

This directory contains architecture and design diagrams.

## Files
- `logical-topology.mmd`: End-to-end logical campus layout.
- `physical-connections.mmd`: Physical/link-level connection intent.
- `vlan-ip-plan.md`: VLAN/subnet design tables.
- `ospf-routing-design.md`: OSPF area/linking model.
- `hsrp-stp-alignment.md`: Gateway/root-role alignment table.
- `wireless-wlc-capwap-flow.md`: WLC/LWAP control/data flow notes.

If rendered PNGs are missing or outdated, use Mermaid/Markdown sources in this folder as the canonical editable diagrams.
