# Validation Checklist

## Layer 2
- `show vlan brief`
- `show interfaces trunk`
- `show etherchannel summary`
- `show spanning-tree root`
- `show spanning-tree vlan 10,20,30,40,99`

## Layer 3
- `show ip interface brief`
- `show standby brief`
- `show ip ospf neighbor`
- `show ip route ospf`

## Services
- `show ip dhcp binding`
- `show ip dhcp pool`
- `show ntp status`
- `show logging`
- `show snmp`
- `show ip nat translations`
- `show ip nat statistics`

## Security
- `show access-lists`
- `show ip ssh`
- `show port-security`
- `show port-security address`
- `show ip dhcp snooping`
- `show ip arp inspection`

## Wireless
- WLC GUI/CLI AP summary
- WLC GUI/CLI client summary
- AP CAPWAP join status

## IPv6
- `show ipv6 interface brief`
- `show ipv6 route`
- `show ipv6 protocols`
